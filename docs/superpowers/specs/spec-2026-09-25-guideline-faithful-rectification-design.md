# 指南忠实化校直设计（guideline-faithful rectification）

日期：2026-09-25
状态：设计已获用户批准（含决策点 A），待 spec 审阅
上游输入：《岗位AI技能共现率执行指南》v1.5（docs/exchange/01_研究设计/岗位AI技能共现率执行指南.md）
关联：docs/00_实验交接说明_panel_v2ac.md、docs/21_交接合规审查矩阵_v2i.md

## 1. 背景与目标

从指南 v1.5 到 v2h 交付与 v2i 链的多个 PR 层层累积了实现偏离（放宽的验收阈值、
改动的推理参数、简化的抽样规则），使结果中的异常现象无法归因：不知道是
数据/方法的真实性质还是实现偏离的产物。

目标：**口径性偏离回归指南原值，工程性偏离保留并留痕**；校直后对三个"奇怪
结果"给出归因判定；v2i 链按指南口径推进到 v2i 门 formal_pass。

已批准的决策：
- 忠实策略：口径归指南、工程留痕（max_output_tokens 12288、max_model_len
  24576、断点/并发机制等工程项保留，guideline_deviations 如实记录）。
- 重点复核对象：2022 反常峰值、2023 深谷+档位越严跌越深、零技能率与主指标
  强负相关（-0.82）。（不含 11.18% 绝对水平。）
- 范围：主链（v2a-v2h）与 v2i 新链都校；discovery_frame 构建继续跑完。
- 执行方式：多子代理并行，算力换时间。

## 2. 三线设计

### 线 1：诊断线（只读分析，3 子代理并行）

对已交付 v2h 产物（output/release/panel_v2h/ 与结果库）做归因，不改代码：

- **1a 2022 峰值**：51Job 2022 样本量逐年对照；blank 治理彻底性（净化残留、
  跨年链式去重对邻年的误伤）；固定平台混合直接标准化年度曲线，检验峰值是否
  为构成效应。
- **1b 2023 深谷**：平台构成变化分解（标准化法）；六锚组×年份命中率分解
  （LLM 组"禁裸大模型"为重点怀疑）；零技能机械效应完整量化（docs/00 已量化
  1/4，补齐其余归因）；得分分布逐年位移检验（档位越严跌越深是数学必然还是
  独立信号）；v2d↔v2h 词表代际敏感性复核。
- **1c 零技能率驱动**：零技能岗位画像逐年变化（文本长度/平台/岗位组）；
  词典覆盖随年份退化检验。

产出：每题归因判定（实现偏差/数据因素/真实现象）+ 修复点清单。

### 线 2：口径线（discovery_formal 按 §9.2 忠实重写，TDD）

- 抽样两阶段：年内先行业保底 min(50, 该行业岗位数)；剩余名额按行业剩余
  岗位数比例分配；舍入差额按行业剩余岗位数由大到小补齐（§9.2.3-4 逐字）。
  保底部分行业内部仍按其余五维（岗位组/规模/文本长度/技术/平台）分层。
- 恢复覆盖率提升 <0.1pp 为停止条件（§9.2.2.2）：每轮新别名并入临时词典后
  对全部去重岗位执行一次确定性匹配计算覆盖率（复用既有 automaton；约
  2300 万行/轮，可接受小时级成本）。
- 饱和条件 3（各年份与主要行业至少入样一批次）恢复 finalize 校验。
- 饱和条件 4（主锚点命中岗位未覆盖比例不再明显下降）首次实现。
- **量化定义（决策点 A，已批准）**："不再明显下降" = 连续两轮降幅
  <0.1pp；"主要行业" = 该年岗位数 ≥100 的行业。两者作为 guideline
  clarification 记入 manifest。

### 线 3：基准线（阈值回归 + 批不变重测）

- model_config_v1 删除 acceptance 放宽段，THRESHOLDS 指南原值直接生效；
  工程参数保留并留痕。
- 启用 VLLM_BATCH_INVARIANT=1 重启 vLLM（重启窗口先经用户确认）。
- 防浪费分步：先 100 条配对快测 repeat_exact → 数字可行才跑整轮 technical
  （2 候选×2000 调用）+ prerun 10000 条。
- 产出：真实指标 vs 指南阈值差距报告；达不到的项由用户一次性裁决并记录。

### 汇合

诊断 + 基准数字 → 用户裁决（不达标阈值处置；2022 是否剔除交付表）；
v2i 按指南口径推进；最终交付《归因报告 + 指南口径执行记录》。

## 3. 验收标准

1. 诊断三题各有归因判定与证据等级；实现偏差项附可执行修复点。
2. discovery_formal 新抽样通过逐条对指南算例的单元测试（保底/比例/补齐
   的数值行为）；finalize 校验与 §9.2.2 四条件一致。
3. 基准线产出批不变模式真实指标；阈值判定使用指南原值；裁决留痕。
4. v2i 门 formal_pass 时，manifest 链无未披露的口径偏离。

## 4. 风险与依赖

- vLLM 重启影响 LLM 相关任务窗口（先确认空闲）。
- 基准线与 frame 扫描分别占 GPU/DB，可并行；诊断线只读不抢资源。
- 批不变模式 repeat_exact ≥0.95 无先验保证——快测先行，不行即走裁决路径。
- discovery_formal 口径变更后，v2i 此前未跑的环节全部使用新口径，无历史
  产物需重算（frame 只依赖源库快照与 v3 词表，不受抽样口径影响）。

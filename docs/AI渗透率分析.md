# AI 渗透率分析

> 更新日期：2026-09-02（含全国 392 城扩展）  
> 数据：eps 数据库（独立 PG，1431GB，2014-2024 全国招聘数据）

---

## 一、数据来源

- **数据库**：`eps`（`dbname='eps'`，独立于 Employ26）
- **分片表**：按城市分片，每城三张——`job_`（岗位）、`comp_`（待遇）、`ent_`（企业，含 `industry_code` 行业）
- **分析范围**：初为广州（`job_p0387`）+ 深圳（`job_p0389`）全量；2026-09-02 扩展至**全国 392 市/区县级分片全量**（2014-2024 共 11 年，2024 年约 1.22 亿条有效岗位广告，流式不抽样；行业明细仍为广深两市）
- **行业**：经 `recruit_id` 关联 `ent_` 企业表 `industry_code`（空值归"未知"）

## 二、方法（两套最终方法，交叉验证）

### 方法A：加权判定（关键词 + AI 技能词典）

岗位是否 AI 相关 = 岗位名命中 AI 关键词 + 岗位描述命中 AI 技术技能词，两部分加权：

```
score = 岗位名关键词得分 + 岗位描述技能词得分
AI 判定：score >= 3
```

权重分层（词典以 `词|权重` 标注）：

| 层级 | 权重 | 说明 | 示例 |
|---|---|---|---|
| 特定 AI 技术词 | 3 | 单独出现基本即 AI | PyTorch、SLAM、轨迹预测、RAG |
| 通用强词 | 2 | 公司简介/模板常用，需佐证 | 深度学习、大模型、人脸识别、AIGC |
| 弱词 | 1 | 歧义大，需共同佐证 | AI设计(排除Adobe)、内容安全、岗位名中的"AI" |

**三个口径**：
- **关键词率**：岗位名关键词得分 ≥ 3
- **AI技能率**：描述技能词得分 ≥ 3
- **综合率**：关键词 + 技能合计 ≥ 3（加权并集）

**关键规则**：
- 纯英文词（RAG/LLM/AI）词边界匹配，避免英文子串误报（如 RAG 误匹配 BEVERAGE）
- "AI设计"后紧跟"软件"排除（=Adobe Illustrator）
- 剔除岗位名含公司名特征的括号（如"电气工程师(机器人公司)"）

### 方法B：锚点共现法（LLM 挖掘 + 技能-技能共现）

完全数据驱动，不依赖手工词典权重与岗位名。技能词表由 LLM 从招聘数据挖掘（`dicts/ai_skill_terms_llm.txt`，4,788 词 + 通用技能 ≈ 6,872 项）。

**两阶段计算**：
1. **技能 AI 相关度 ωsAI**：技能 s 与 AI 锚点技能（机器学习/深度学习/计算机视觉/自然语言/语音识别/强化学习/神经网络）的共现比例

   ```
   ωsAI(s) = P(岗位含锚点技能 | 岗位含技能 s) = N(s ∩ 锚点) / N(s)
   ```

2. **岗位 AI 相关度 ωjAI 与判定**：岗位全部技能 ωsAI 的平均值，`ωjAI >= 0.10` 判为 AI 岗位

**词典迭代**：三轮迭代（初始合并 → 扩大 LLM 挖掘 → 别名生成），词典 3,415 → 6,872 词，
覆盖（每岗位技能命中）从 89.6% 提升到 92.9%。

### 方法C：融合判定（方法 A 或 方法 B-过滤）

两法互补：A 擅长抓"岗位名 AI"岗，B 擅长抓"描述技能 AI"岗。融合取并集并过滤 B 噪声：

```
融合 AI = 方法A判AI 或 (方法B判AI 且 ωjAI>=0.15 且 max ωsAI>=0.5)
```

- B 噪声过滤排除模板/词误匹配误判（如"薪资算法"送餐、"图像处理"美工、模板提"深度学习"的绿建岗）
- 融合率 = A率 + B-过滤补召回率，介于 A 与 B 之间
- 按年抽样估算（`fusion_sampling.py`）：2024 广州 0.43%、深圳 0.91%

### 工程实现

| 模块 | 功能 |
|---|---|
| `stream_penetration.py` | 加权判定全量流式渗透率（逐年断点） |
| `ai_scoring.py` | 加权判定核心（关键词+技能得分，阈值 3） |
| `anchor_penetration.py` | 锚点共现法全量渗透率（ωsAI + ωjAI，逐年断点） |
| `skill_ai_anchor.py` | 锚点共现核心（技能-技能共现、ωsAI/ωjAI） |
| `llm_skill_mining.py` | LLM 挖掘 AI 技能词（数据驱动扩充词典） |
| `penetration_detail.py` | 三时间粒度 × 城市 × 行业 × 三方法明细 |
| `sample_check.py` | 抽样复核（多选/漏选检查） |

## 四、细分明细数据结构

`penetration_detail.py` 输出**三时间粒度（年度/半年度/季度）× 城市 × 行业 × 三方法**明细，两张 CSV：

- 宽表：`output/reports/ai_penetration_detail_{时间戳}.csv`
- 季度明细：`output/reports/ai_penetration_quarterly_{时间戳}.csv`

| 列 | 说明 |
|---|---|
| `时间粒度` / `年份` / `期间` | 年度（全年）/ 半年度（上·下半年）/ 季度（Q1-Q4） |
| `城市` | 广州 / 深圳 |
| `行业` | ent 企业表 `industry_code` 归类到 GB/T 4754 **大类层面**（门类字母+大类名，如 `C22造纸和纸制品业`、`I65软件和信息技术服务业`；空值归"未知"） |
| `总发布数` | 该组合下岗位总数 |
| `AI岗位发布数_关键词` | 关键词法命中数（岗位名得分≥3） |
| `AI岗位发布数_共现率` | AI技能词典法命中数（描述得分≥3） |
| `AI岗位发布数_复合方法` | 加权并集命中数（关键词+技能合计≥3） |
| `AI岗位渗透度_关键词` / `_共现率` / `_复合方法` | 对应发布数 ÷ 总发布数 |

**样本量阈值**：城市-行业-时间段总发布数 < **500** 时剔除该组合（不计算渗透度），避免小样本噪声。

## 五、结论

1. **AI 渗透率逐年上升**：方法 A 合计综合率从 2014 年 0% 升至 2024 年 **0.62%**（广州 0.40%、深圳 0.80%）；融合口径 2024 年广州 0.44%、深圳 0.91%；**全国 2024 融合率 0.47%（1.22 亿发布、北京 1.88% 断层第一）**
2. **深圳是 AI 核心城市**：各口径一致，2024 年深圳约为广州 2 倍
3. **趋势三阶段**：2016-2020 爬坡（深度学习→大模型萌芽）、2021-2023 平台期、2024 跳升（大模型应用落地）；各口径形态一致
4. **行业梯度**：AI 高度集中在信息产业链（I65 软件信息、I63 电信、C39 电子设备、M73 研究试验），传统制造/农业/资源行业渗透率近 0
5. **方法学**：加权判定（三层权重+阈值 3）精度高（抽样复核 ~85-90%）；锚点共现法完全数据驱动（LLM 挖掘词典 + 技能共现）；**融合判定**（A 或 B-过滤）取两法互补、平衡召回与精度，为最终口径；多法交叉验证趋势一致，增强结果可信度

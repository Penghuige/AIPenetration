## 2. 总体结论

后半段指标计算链（锚点口径、annual/pooled/roll3 计数、Beta-Binomial、
岗位简单平均、0.05 主阈值、零技能规则、企业留一）总体已按指南落地。

主要缺口集中在“正式词典 → 全量匹配 → 发布”之间。审查确认旧 v2h 存在以下
会影响正式岗位—技能集合或其可审计性的结构性偏差：

1. A 级同形激活别名用 `min(skill_id)` 猜主概念，而非词典
   `primary_skill_id`；
2. 正式 matcher 未实现指南 §11 的最长匹配优先；
3. legacy T2 已输出“映射到既有 A 概念 / NEW / AMBIGUOUS”，但旧 merge 未把
   映射结果落实到正式 skill_id；
4. 低频 C 的“新技术”分支曾用 `first_year>=2019` 代理，T2 后续真实
   `new_tech` 判断未用于纠正代理；
5. pass2 通过 rid-only 找 raw 拷贝，未强制绑定 dedup 选出的 canonical
   description；
6. `job_skill_long` 未持久化 surface/span/method/ambiguity/tier/version，
   §17.6 原文跨度门被代码自行标成 waived；
7. 最终 `skill_concept_v1` 只有 A 级，而 `skill_candidate_d_v1` 又把全部
   legacy union 统一标成 D，导致“B/C 正式参与计算”和发布语义冲突。

因此：**master 上现有 v2h 应视为 2026-09-10 历史发布代，而不是经过本次
原始交接再验收后的新终版。** 本 PR 修正上述实现后，需要重新执行语义 merge、
formal scan 和 v2h 才能产生新的可声明终版结果。

## 4. 已确认的“合理后续偏离”，不在本 PR 擅自回滚

### 4.1 样本实际止于 2024

原始设计写 2014–2025；后续确认源库实际没有 2025。当前实现按可得年运行并在文档
披露，属于数据不可得，不是把 2025 悄悄漏跑。

### 4.2 描述长度 >=10 与 position 非空准入

原指南把过短文本/岗位名缺失更多视为质量标记或建议字段；后续项目为治理 2022
blank-description 事故，正式样本增加 trim>=10 和 position 非空准入。该规则已在
后续交接文档与 duplicate_version 中登记，且回滚会改变 22.96M 主样本。

本 PR **不擅自回滚**。若接收方要求“逐字回到最初 v1.5”，应单独做样本口径
重跑并比较，而不是在代码审计 PR 中静默改变母样本。

### 4.3 B/C 扩词停止

原始 handoff 规划了继续按年份×行业分层发现新技能；后续交接记录了用户决定
“停止一切增词扩张，只出不进”。因此当前已有 legacy 候选的治理必须合规，
但本 PR 不重新开启新词发现。

这意味着不能再宣称“原始 §8–9 发现任务按字面完整执行”；正确表述应为：
**发现阶段被后续范围决策提前停止，已有候选继续按 §10 正规化后进入/退出正式词典。**

## 5. 本 PR 修复后必须执行的新正式链

由于 primary alias、concept mapping、longest-match 与 canonical 文本绑定都会改变
岗位—技能集合，禁止只重新生成 metadata 或沿用旧 v2h 数字。

建议新 run 使用新的 run id（示例仅用于说明）：

```bash
# 1. 使用既有 T1/T2 结果重新落实 §10.3 语义 grade / formal_skill_id
python -X utf8 -m src.ai_penetration.panel_v2.lexicon_llm merge

# 2. 正式 A/B/C + canonical 文本重扫（不要复用旧 pass2b vocab stamp）
python -X utf8 -m src.ai_penetration.panel_v2.scan --out-tag b

# 3. counts → relevance → scoring → quality → §18 release
python -X utf8 -m src.ai_penetration.panel_v2.v2h --run-id <NEW_RUN_ID>
```

运行后至少核对：

- 新 `quality_control_report.md` 十项阻断全部通过；
- `quality_stats.json` 不由失败运行推进 baseline；
- `skill_concept_v1` 中仅 A/B/C，`skill_candidate_d_v1` 仅 D；
- `job_skill_long` 的 `(job_id, skill_id)` 唯一、证据字段齐全；
- 新旧 v2h 的岗位数、pair 数、005/010/015、年度曲线、zero-skill、LOO 差异；
- 任何主结果变化均按新 run_id 报告，旧数字保留为历史代，不覆盖历史记录。
